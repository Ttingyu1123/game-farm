# 🌱 療癒小農場 Cozy Pocket Farm

原創 2D 點擊式農場經營遊戲。純 HTML5 + CSS3 + JavaScript ES6 Modules，**零依賴、零建置**，
存檔使用 localStorage，支援離線成長。所有美術為 Emoji / CSS 原創 placeholder，無版權素材。

## 快速開始

不需安裝任何依賴，只需要一個靜態伺服器（ES Modules 不能用 `file://` 直接開）：

```bash
# 方法一：Python（內建）
python -m http.server 5317
# 方法二：Node
npx serve -l 5317 .
```

打開瀏覽器前往 <http://localhost:5317/> 即可遊玩。

## 操作說明

1. **選工具再點農地**：下方工具列選擇 🪓翻土／💧澆水／🧺收成／🧹清理，或直接點種子、道具。
2. 再點一次工具可取消選擇；未選工具時點農地會顯示該格資訊。
3. **核心循環**：翻土 → 播種 → 澆水（澆水後才開始生長）→ 等待 → 收成 → 倉庫出售或交付訂單 → 賺金幣經驗 → 買種子、解鎖農地、升級倉庫。
4. 右側面板：🛒商店（買種子/道具）、📦倉庫（出售/擴容）、🎒背包、📋訂單、✅每日任務。
5. 鎖定農地（🔒）點擊可查看解鎖等級與價格。
6. 天氣：⛅多雲生長 +15%；🌧️雨天自動澆水。
7. ⚙️設定：音效開關/音量、手動存檔、重看教學、清除存檔。

## 核心機制

- **時間**：作物存「已累積生長毫秒數」，每 tick 以時間戳差值推進（分頁休眠也正確）；
  讀檔時用 `lastSavedAt` 與現在時間補算離線成長（中性 1.0 倍率，上限 12 小時）。
- **存檔**：重要操作後 debounce 0.8s 自動存檔 + 每 20 秒定時存檔 + 關頁前存檔；
  舊存檔缺欄位以預設值補齊（migrate），JSON 損壞時安全退回開始畫面。
- **防呆**：金幣/庫存不可為負、倉庫滿不可收成、訂單/任務/升級獎勵先改狀態再發獎（不可重複領取）、
  解鎖農地防重複扣款、快速連點安全。

### v1.1 深度更新

- **🐛 害蟲事件**：生長中作物隨機被害蟲入侵（同時最多 2 隻），生長暫停；點擊驅趕 +2 經驗，雨天自動沖走害蟲。教學期間不觸發。
- **🥀 枯萎風險**：成熟後放置超過 3× 生長時間會枯萎，只能用清理工具清除。離線時間不計入（回來重新計時），教學期間不觸發。
- **⭐ 優質作物**：收成 10% 機率出優質品（施過肥 +15% → 25%），獨立庫存、售價 ×2。
- **📈 市場行情**：售價每 5 分鐘在 80%～140% 間波動（新遊戲首 5 分鐘固定 1.0），倉庫顯示漲跌幅，賣菜挑時機。
- **🏆 成就系統**：12 個成就（收成/出售/賺錢/訂單/等級/地圖/除蟲/優質/倉儲），自動偵測發放金幣，成就頁查看進度。

### v1.2 季節系統

- **🌸 四季輪替**：春→夏→秋→冬，每 10 分鐘一季，農場背景隨季節變色。
- **當季/逆季**：當季作物生長 +30%、優質機率 +10%；逆季 -30%。商店與農地提示都會標示，鼓勵輪作。
- 季節分配：春（胡蘿蔔/草莓）、夏（番茄/玉米）、秋（南瓜/小麥）、冬（只有小麥耐寒，番茄/草莓受凍）。
- 新遊戲固定從春天開始（新手作物胡蘿蔔當季）；離線期間季節照常輪替（保留相位），但離線成長以中性倍率計算。

## 已知限制

- 離線期間以晴天倍率補算（離線時天氣未知，採中性值）；離線不會枯萎、不出害蟲。
- 訂單只收一般品，優質作物僅供出售（設計上讓優質品走市場路線）。
- 灑水器不佔用倉庫、放置後佔用一格農地；無法移動只能收回重放。
- 音效為程式生成短音，無背景音樂。
- 觸控裝置無 hover 提示，改以「未選工具點擊格子」顯示資訊。
