# 🌱 療癒小農場 Cozy Pocket Farm

原創 2D 點擊式農場經營遊戲。純 HTML5 + CSS3 + JavaScript ES6 Modules，**零框架、零建置**，
存檔使用 localStorage，支援離線成長。美術為 92 個自製貼紙風圖示（AI 生成後切圖）加 CSS 場景，
背景音樂為四季各一首 Suno 生成的器樂曲。

正式站：<https://game-farm.tingyudeco.com/>（push `main` 即由 GitHub Pages 自動部署）

## 快速開始

不需安裝任何依賴，只需要一個靜態伺服器（ES Modules 不能用 `file://` 直接開）：

```bash
# 方法一：Python（內建）
python -m http.server 5317
# 方法二：Node
npx serve -l 5317 .
```

打開瀏覽器前往 <http://localhost:5317/> 即可遊玩。

## 操作說明

1. **選工具再點農地**：下方工具列選擇 🪓翻土／💧澆水／🧺收成／🧹清理，或直接點種子、道具。
2. 再點一次工具可取消選擇；未選工具時點農地會顯示該格資訊。
3. **核心循環**：翻土 → 播種 → 澆水（澆水後才開始生長）→ 等待 → 收成 → 倉庫出售或交付訂單 → 賺金幣經驗 → 買種子、解鎖農地、升級倉庫。
4. 右側面板：🛒商店（買種子/道具）、📦倉庫（出售/擴容）、🎒背包、🏭工坊、📋訂單、📝每日任務、🏆成就。
5. 鎖定區是一整片荒地加一塊告示牌，寫著區名、解鎖等級與價格，點擊即可解鎖。
   農地狀態看外觀：雜草地是未整理、犁溝是已翻土、深色土是已澆水、冒水滴徽章是缺水。
6. 天氣：⛅多雲生長 +15%；🌧️雨天自動澆水。
7. ⚙️設定：音效開關、背景音樂開關、音量、手動存檔、重看教學、清除存檔。

## 核心機制

- **時間**：作物存「已累積生長毫秒數」，每 tick 以時間戳差值推進（分頁休眠也正確）；
  讀檔時用 `lastSavedAt` 與現在時間補算離線成長（中性 1.0 倍率，上限 12 小時）。
- **存檔**：重要操作後 debounce 0.8s 自動存檔 + 每 20 秒定時存檔 + 關頁前存檔；
  舊存檔缺欄位以預設值補齊（migrate），JSON 損壞時安全退回開始畫面。
- **防呆**：金幣/庫存不可為負、倉庫滿不可收成、訂單/任務/升級獎勵先改狀態再發獎（不可重複領取）、
  解鎖農地防重複扣款、快速連點安全。

## 素材產線

### 新增或重做圖示

1. 用 `codex exec --skip-git-repo-check --sandbox workspace-write "…image_gen…" < /dev/null` 在 repo 外的工作目錄生成一張多格圖（一張 6 到 9 個）。提示詞沿用同一組風格詞才會一致：cozy cartoon farm-game sticker icons、chunky rounded shapes、thick dark brown outline (#4e3d2c)、flat warm colors、no pure white fills、pure white background。作物一排四格：幼株／開花結果／成熟株／收成品。
2. 每張圖放在 `<sheet>/<sheet>.png`，在 `tools/slice_icons.py` 的 `SHEETS` 補上格數與檔名，執行 `python tools/slice_icons.py <輸出目錄>`，再把 PNG 複製到 `assets/icons/`。需要 Pillow 與 numpy。
3. 新作物要有 `crop-<id>-1.png`、`-2`、`-3` 與 `crop-<id>.png` 四張，並在 `icons.js` 的 `EMOJI_ICON` 加上該作物的 emoji。其他新圖示要先在資料表給它一個沒被別人用過的 emoji，再加進對照表。

原始的多格圖沒有收進 repo。

### 更換背景音樂

1. 轉成 AAC：`ffmpeg -i <來源> -af "afade=t=in:d=0.8,afade=t=out:st=<結尾前2.5秒>:d=2.5,volume=<增益>dB" -c:a aac -b:a 112k -movflags +faststart <季節>.m4a`，增益取到整體響度約 -22 LUFS。
2. 上傳：`wrangler r2 object put "tingyu-music/game-farm/bgm/<季節>.m4a" --file <檔案> --content-type audio/mp4 --remote`。
3. 檔名是 `spring`、`summer`、`autumn`、`winter`，覆蓋同名檔即可，不用改程式。目前四首來自 Suno 曲庫的 MedEdu 系列（03、18A、12、17A）。

## 踩坑記錄

#### 2026-11-16 每個 tick 重設文字會讓圖示反覆重建
- **問題**：圖示替換上線後出現 `Cannot read properties of null (reading 'insertBefore')`，HUD 的圖示也在閃。
- **根因**：HUD 每 250ms 重設 `textContent`，監看器排到時原本的文字節點已經被換掉；同時每次重設都會重建一次 `<img>`。
- **解法**：`iconizeText` 先檢查 `parentNode`；HUD 改用 `setText()`，內容沒變就不寫入。
- **預防**：會定時更新、又含對照表內 emoji 的元素，一律先比對再寫。

#### 2026-11-16 emoji 撞號
- **問題**：🧃 同時是果汁機與番茄汁的圖示，對照表只能對到其中一個。
- **解法**：果汁機改用 🌀、肥料改用 🧴。新增項目前先查 `EMOJI_ICON` 有沒有人用過。

#### 2026-11-16 mp3 轉檔後長度錯誤
- **問題**：轉出的 mp3 檔頭長度只有實際的三分之一。
- **根因**：這台機器 PATH 上的 ffmpeg 是 Topaz 附的，mp3 只有 `mp3_mf` 編碼器，寫出的檔頭不可靠。
- **解法**：改輸出 AAC（`.m4a`），所有瀏覽器都能播。

#### 2026-11-16 曲庫記錄的長度不準
- **問題**：照曲庫 `library.json` 的長度下淡出，兩首曲子的淡出落在檔案結尾之後，等於沒淡出。
- **解法**：先用 ffmpeg 解碼量出實際長度，再決定淡出起點。

#### 2026-11-16 iPhone 不能用程式調音樂音量
- **根因**：iOS 的 `<audio>.volume` 是唯讀的。
- **解法**：把音檔本身的響度壓低到 -22 LUFS；音量滑桿在桌機與 Android 仍然有效。

#### 2026-11-16 作物換階段時空白一瞬間
- **問題**：作物第一次進入新生長階段時，新圖還沒載入，該格會空白一下。
- **狀態**：未修。之後有快取就不會再出現；預先載入 `assets/icons` 可以解決。

## 已知限制

- 離線期間以晴天倍率補算（離線時天氣未知，採中性值）；離線不會枯萎、不出害蟲。
- 訂單只收一般品，優質作物僅供出售（設計上讓優質品走市場路線）。
- 灑水器不佔用倉庫、放置後佔用一格農地；無法移動只能收回重放。
- 音效為程式生成短音；背景音樂需要連網，離線時改播程式生成的備援音樂。
- 觸控裝置無 hover 提示，改以「未選工具點擊格子」顯示資訊（含作物剩餘時間）。
- 字體從 Google Fonts 載入，離線或載入失敗時退回系統字體。
- 成就、訂單顧客、節慶與粒子特效仍使用 emoji，尚未換成自製圖示。
- v1.8 的美術與音樂只在 Chromium（桌機與手機視窗模擬）驗證過，尚未在 iPhone 真機確認。
